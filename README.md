### 🐧 No Linux (Ubuntu / Mint / Debian)

    Abra o seu gerenciador de arquivos, vá até a pasta, dê **dois cliques** sobre o arquivo executável `INICIAR Linux` e selecione a opção **"Executar no Terminal"**.

    Abra o terminal dentro da pasta do projeto e digite o comando abaixo:
