## 💻 Como Usar

### 🌐 Navegador (Recomendado Uiversal)\
## Este funciona em Celular e em todos os sistemas operacionais com navegador
*   Abra a pasta do projeto e dê **dois cliques** diretamente no arquivo `Index.html`.

### 🪟 No Windows
*   Abra a pasta do projeto e dê **dois cliques** diretamente no arquivo `jogar.bat`.

---

### 🐧 No Linux (Ubuntu / Mint / Debian)
*   **Via Dois Cliques (Rápido):** 
    Abra o seu gerenciador de arquivos, vá até a pasta, dê **dois cliques** sobre o arquivo executável `INICIAR Linux` e selecione a opção **"Executar no Terminal"**.
*   **Via Terminal:** 
    Abra o terminal dentro da pasta do projeto e digite o comando abaixo:
    ```bash
    python3 *Nitro*.py
    ```
